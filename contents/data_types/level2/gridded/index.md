# Gridded data

Gridded products describe spatial fields around the platform: [roughness images](roughness_images.md) and [roughness image mosaics](roughness_mosaics.md) on time-bounded local Cartesian grids stored as NetCDF groups, and [near-surface current](current_maps.md), [bathymetric](depth_maps.md), and [sea ice drift](sea_ice_drift.md) maps whose analysis locations, placed on an overlapping, approximately regular grid that follows the platform, are stored as points on a flat `measurement` dimension.
