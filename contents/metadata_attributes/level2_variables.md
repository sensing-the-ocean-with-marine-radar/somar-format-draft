# Level 2 variables

This page defines the data, ancillary, and coordinate variables of the [Level 2 products](../product_types/level2/index.md), apart from the coordinates and quality flag that all products of a kind share.
Each variable keeps its meaning in every product that carries it; which products require, recommend, or allow it is stated with the products (see [SOMaR product types](../product_types/index.md)).
The convention a variable is taken from is named in small print under it (see [Metadata](index.md#reading-the-tables)); a variable marked CF carries the CF standard name of the same name, unless its description says otherwise.

In the column of values, `(…)` stands for the dimensions of a single value set of the product: the dimensions of the horizontal grid, such as `(latitude, longitude)` or `(y, x)`, for products on a grid, and `(time)` for products indexed by measurement.
Dimensions written beside it, such as `(…, wave_frequency)`, are added in the position shown.

Some variables are only meaningful together with others.
Their descriptions state this in one of two forms, which apply in every product: "Carried together with `x`." means that a file that carries the variable also carries `x`, and vice versa; "Requires `x`." means that a file that carries the variable also carries `x`, in the same group or in one of its ancestors.

| Variable | Values | Description |
|---|---|---|
| `background_noise`<br><small>SOMaR</small> | double `(…)`; `1` | Spectral density of the background noise in the radar images, used by the signal-to-noise ratio method to derive the significant wave height. Carried together with `wave_signal`. |
| `correlation_coefficient`<br><small>SOMaR</small> | double `(…)`; `1` | Peak Pearson correlation coefficient of the forward cross-correlation from which the sea ice drift is retrieved. |
| `correlation_coefficient_backward`<br><small>SOMaR</small> | double `(…)`; `1` | Peak Pearson correlation coefficient of the backward cross-correlation. Requires `eastward_sea_ice_velocity_backward` and `northward_sea_ice_velocity_backward`. |
| `eastward_sea_ice_velocity`<br><small>[CF][cf-names]</small> | double `(…)`; `m s-1` | Eastward component of the sea ice drift, from the forward retrieval, i.e. from the earlier to the later of two radar images. As the CF standard name implies, the drift is given relative to the ground, with the platform motion removed, and points in the direction toward which the ice drifts. Carried together with `northward_sea_ice_velocity`. |
| `eastward_sea_ice_velocity_backward`<br><small>[CF][cf-names]</small> | double `(…)`; `m s-1` | Eastward component of the sea ice drift, from the backward retrieval, i.e. from the later to the earlier of the two radar images, as an independent estimate of the same drift. Carries the standard name `eastward_sea_ice_velocity`. Carried together with `northward_sea_ice_velocity_backward`. |
| `eastward_sea_water_velocity`<br><small>[CF][cf-names]</small> | double `(…)`; `m s-1` | Eastward component of the near-surface current. As the CF standard name implies, the current is given relative to the ground, with the platform motion removed, and points in the direction toward which the water flows. It is retrieved from the current-induced Doppler shift of the surface waves and is therefore a depth-weighted average, with the surface current carrying the greatest weight (Stewart and Joy [1974](../references/index.md#stewart-joy-1974)); its effective depth is indicated by `mean_wavenumber`. Retrieved within analysis windows that move with the platform, it is given after subtracting the mean platform velocity. Carried together with `northward_sea_water_velocity`. |
| `eastward_sea_water_velocity_standard_error`<br><small>SOMaR</small> | double `(…)`; `m s-1` | Standard error of the eastward component of the near-surface current, e.g. from a least-squares fit. Requires `eastward_sea_water_velocity`. Carried together with `northward_sea_water_velocity_standard_error`. |
| `eastward_wave_wavenumber`<br><small>SOMaR</small> | double `(eastward_wave_wavenumber)`; `m-1` | Coordinate variable: the eastward wavenumber component of a two-dimensional wavenumber spectrum. Wavenumbers are cyclic, i.e. the reciprocal of the wavelength. By SOMaR convention, consistent with the from-direction of the frequency-direction spectra, the wavenumber vector points toward the direction from which the waves come, i.e. opposite to the direction of propagation. |
| `mean_wavenumber`<br><small>SOMaR</small> | double `(…)`; `m-1` | Mean wavenumber of the wave signal used in the retrieval, cyclic, i.e. the reciprocal of the wavelength. It indicates the effective sensing depth of a current retrieval, approximately 4–8% of the corresponding wavelength, and, for a bathymetry retrieval, the greatest depth that can be retrieved, approximately 30% of that wavelength. |
| `northward_sea_ice_velocity`<br><small>[CF][cf-names]</small> | double `(…)`; `m s-1` | Northward component of the sea ice drift, from the forward retrieval, defined as `eastward_sea_ice_velocity`. Carried together with `eastward_sea_ice_velocity`. |
| `northward_sea_ice_velocity_backward`<br><small>[CF][cf-names]</small> | double `(…)`; `m s-1` | Northward component of the sea ice drift, from the backward retrieval, defined as `eastward_sea_ice_velocity_backward`. Carries the standard name `northward_sea_ice_velocity`. Carried together with `eastward_sea_ice_velocity_backward`. |
| `northward_sea_water_velocity`<br><small>[CF][cf-names]</small> | double `(…)`; `m s-1` | Northward component of the near-surface current, defined as `eastward_sea_water_velocity`. Carried together with `eastward_sea_water_velocity`. |
| `northward_sea_water_velocity_standard_error`<br><small>SOMaR</small> | double `(…)`; `m s-1` | Standard error of the northward component of the near-surface current, e.g. from a least-squares fit. Requires `northward_sea_water_velocity`. Carried together with `eastward_sea_water_velocity_standard_error`. |
| `northward_wave_wavenumber`<br><small>SOMaR</small> | double `(northward_wave_wavenumber)`; `m-1` | Coordinate variable: the northward wavenumber component of a two-dimensional wavenumber spectrum, defined as `eastward_wave_wavenumber`. |
| `number_of_observations`<br><small>[CF][cf-names]</small> | int `(…)`; `1` | Number of Level 1b images that contributed to each grid cell of a roughness image or mosaic. |
| `number_of_wave_coordinates`<br><small>SOMaR</small> | int `(…)`; `1` | Number of points of the wave signal in the wavenumber-frequency spectrum that were used in a least-squares fit. |
| `scan_sectors`<br><small>SOMaR</small> | byte `(…)`; `0b`, `1b`, `2b` | Flag variable of a roughness image mosaic: the part of the radar scan, relative to the target area, that the observations of each grid cell belong to, with the `flag_meanings` `preceding_target_area` (0), `inside_target_area` (1), and `trailing_target_area` (2). |
| `sea_floor_depth_below_sea_surface`<br><small>[CF][cf-names]</small> | double `(…)`; `m` | Water depth, from the sea surface to the sea floor. As the CF standard name implies, it is the depth below the actual sea surface during the measurement period, as sensed by the waves, and therefore includes the tide and other sea level variations; it is not tide-corrected. |
| `sea_floor_depth_below_sea_surface_standard_error`<br><small>SOMaR</small> | double `(…)`; `m` | Standard error of the water depth, e.g. from a least-squares fit. Requires `sea_floor_depth_below_sea_surface`. |
| `sea_surface_roughness`<br><small>SOMaR</small> | float `(…)`; `1` or `dB` | Time mean of the radar backscatter power over the averaging window of each grid cell, in uncalibrated analog-to-digital converter units. Level 1b amplitude (`backscatter_amplitude`) is squared, and values in `dB` are converted to linear units, before averaging, and the mean is stored in linear (`1`) or logarithmic (`dB`) units. If the signal cannot be linearized, such as a log-compressed video signal, the mean is taken over the stored Level 1b values instead, the units are `1`, and the `comment` must say so. Carries `cell_methods = "time: mean"`, or `"time: mean (comment: computed on linear power)"` when the units are `dB`, and `coordinates = "time"`. The averaging window of each grid cell starts at `time`, or at `time + start_time_of_observations` in a mosaic, and lasts at most `averaging_duration`; it may be shorter for some cells, as recorded by `number_of_observations`. |
| `sea_surface_wave_directional_spread`<br><small>[CF][cf-names]</small> | float `(…, wave_frequency)`; `degree` | Directional spread of the waves in each frequency band. Requires `wave_frequency`. |
| `sea_surface_wave_directional_variance_spectral_density`<br><small>[CF][cf-names]</small> | double `(…, wave_frequency, sea_surface_wave_from_direction)`; `m2 s degree-1` | Wave energy density as a function of wave frequency and of the direction from which the waves come. Requires `wave_frequency` and `sea_surface_wave_from_direction`. |
| `sea_surface_wave_from_direction`<br><small>[CF][cf-names]</small> | double `(sea_surface_wave_from_direction)` or `(…)`; `degree` | Direction from which the waves come, in degrees clockwise from true north, following the nautical convention for waves. As a coordinate variable, the direction axis of a frequency-direction spectrum. As a data variable, the mean wave direction, whose definition should be documented in a `comment` attribute. |
| `sea_surface_wave_from_direction_at_variance_spectral_density_maximum`<br><small>[CF][cf-names]</small> | double `(…)`; `degree` | Peak wave direction: the direction from which the waves come at the spectral maximum. |
| `sea_surface_wave_mean_from_direction`<br><small>[CF][cf-names]</small> | float `(…, wave_frequency)`; `degree` | Mean direction from which the waves come in each frequency band. Requires `wave_frequency`. |
| `sea_surface_wave_mean_period`<br><small>[CF][cf-names]</small> | double `(…)`; `s` | Mean wave period, e.g. $T_{m01}$ or $T_{m02}$; the spectral moment definition should be documented in a `comment` attribute. Intrinsic or absolute, as given by [`wave_frequency_frame`](../product_types/level2/index.md#processing-parameters). |
| `sea_surface_wave_mean_square_slope`<br><small>[CF][cf-names]</small> | double `(…)`; `1` | Mean square slope of the sea surface, used by the shadowing method to derive the significant wave height. |
| `sea_surface_wave_period_at_variance_spectral_density_maximum`<br><small>[CF][cf-names]</small> | double `(…)`; `s` | Peak wave period: the period at the spectral maximum. Intrinsic or absolute, as given by [`wave_frequency_frame`](../product_types/level2/index.md#processing-parameters). |
| `sea_surface_wave_significant_height`<br><small>[CF][cf-names]</small> | double `(…)`; `m` | Significant wave height. |
| `sea_surface_wave_variance_spectral_density`<br><small>[CF][cf-names]</small> | float `(…, wave_frequency)`; `m2 s` | Wave energy density as a function of wave frequency. Requires `wave_frequency`. |
| `sea_surface_wave_wavenumber_variance_spectral_density`<br><small>SOMaR</small> | double `(…, northward_wave_wavenumber, eastward_wave_wavenumber)`; `m4` | Calibrated wave energy density as a function of the two wavenumber components. It carries no `standard_name`: CF defines `sea_surface_wave_variance_spectral_density` for frequency spectra, in units of `m2 s`, to which `m4` cannot be converted, and the variable is named so as not to be mistaken for it. Requires `eastward_wave_wavenumber` and `northward_wave_wavenumber`. |
| `signal_to_noise_ratio`<br><small>SOMaR</small> | double `(…)`; `1` | Signal-to-noise ratio of the current retrieval, as defined by the method; the definition is given in a `comment` attribute. |
| `start_time_of_observations`<br><small>SOMaR</small> | float `(…)`; `s` | Start of the averaging of each grid cell of a roughness image mosaic, in seconds after `time`. |
| `wave_frequency`<br><small>[CF][cf-names]</small> | double `(wave_frequency)`; `s-1` | Coordinate variable: wave frequency, intrinsic or absolute, as given by [`wave_frequency_frame`](../product_types/level2/index.md#processing-parameters). |
| `wave_signal`<br><small>SOMaR</small> | double `(…)`; `1` | Spectral density of the wave signal in the radar images, used by the signal-to-noise ratio method to derive the significant wave height. Carried together with `background_noise`. |
| `wavenumber_bin`<br><small>SOMaR</small> | double `(wavenumber_bin)`; `m-1` | Coordinate variable: the center of each wavenumber band of a current profile, cyclic. The current retrieval is repeated in each band, and since the effective sensing depth decreases with increasing wavenumber, the bands resolve the current at different depths. Data variables with this dimension carry it immediately before the dimensions of the horizontal grid. Its `bounds` attribute is `"wavenumber_bin_bounds"`. Requires `wavenumber_bin_bounds`. |
| `wavenumber_bin_bounds`<br><small>SOMaR</small> | double `(wavenumber_bin, nv)`; `m-1` | Lower and upper edge of each wavenumber band, along the dimension `nv` (number of vertices, as in [CF][cf-bounds] section 7.1) of size 2, so that the bands need not be of equal width. Requires `wavenumber_bin`. |
